# CRUD de Produtos em Java

Primeiro projeto aplicando conceitos de Orientação a Objetos em Java.

## Funcionalidades

- Cadastrar produto
- Listar produtos
- Buscar produto por ID
- Atualizar produto
- Remover produto

## Conceitos aplicados

- Classes e objetos
- Encapsulamento
- Construtores
- ArrayList
- Scanner
- Switch
- Loops
- Métodos getters e setters
